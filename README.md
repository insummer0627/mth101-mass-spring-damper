# MTH101：周期外力下的质量—弹簧—阻尼系统

本仓库用于小组协作、任务对接与版本管理。核心模型、推导、仿真及提交正文由小组自行完成。

## 六个岗位

成员编号是岗位编号；成员1和成员5由仓库所有者负责。姓名、其他负责人及日期待小组确认。

| 岗位 | 交付物 | 对接对象 |
|---|---|---|
| 1 Background（我） | 工程背景、研究目的、引用资料 | 与2确认背景和模型；与3确认范围；文献交6 |
| 2 模型 | 示意图、假设、运动方程、参数及初始条件表 | 交3、4、5共同使用 |
| 3 理论 | 核心问题、术语解释、比较方案、每张图的问题 | 与4核对；与5解释图；向6提供分析 |
| 4 推导与验算 | 完整推导、解析结果、适用条件、对照案例 | 核对2和3；经复核结果交5 |
| 5 仿真绘图与排版（我） | 自行编写的代码、解析与数值对照、图表、格式稿 | 根据2和4计算；3、4审核；结果交6 |
| 6 结论与文献 | 主要发现、具体局限、参考文献列表 | 根据2、3、5总结；全员审读 |

第7位成员仍按原安排承担协调、全文校对与提交准备。全员参与建模、推导、分析和写作，岗位不代表包办或豁免核心工作。

## 完成顺序

1. 成员1、2、3确认背景和范围。
2. 成员2提交统一条件表。
3. 成员4推导，成员3交叉核对。
4. 成员5完成数值对照和必要图表。
5. 成员3、4审核结果。
6. 成员6完成结论与文献，全员审读。

## 课程要求与协作建议

任务书要求800–1000词正文，包含Background、Description of the model(s)、Explanation of the solutions、Conclusion、References。方程、图和参考文献列表不计入规定正文词数。截止日期、提交格式及评分细则以课程平台为准。

三张图、特定阻尼分类和指定软件均不是已确认的课程硬性要求。课程规定AI仅用于语言润色；本仓库含AI辅助整理的管理文档，不是已批准的使用范例，也不是提交报告。实际使用情况须如实记录，并向教师确认边界。

尚未上传课程PDF、示例报告、个人学号、核心推导或仿真实现。上传前由小组检查内容与分享范围。
